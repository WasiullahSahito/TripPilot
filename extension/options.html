TripPilot assistant settings

Allowed sites

If you list sites here, the assistant refuses to scan any other site unless you tick "Use this site once". Leave it empty to be asked on every site. Only use the assistant on sites whose terms allow assisted form entry.

    Site adapters

    Adapters pin fields to your data more reliably than label matching. Only the local test form is bundled; no real government or embassy portal is, because none has been verified.

      Sites you taught

      Fields you pinned with "Teach this site". Only a field's id or name is stored (never your personal data), and you can share these with someone using the same site.

      Your data

      Exported details are kept in memory only, expire after 30 minutes and are never readable by web pages.

      What the assistant never does

      • It never submits a form or clicks any button or link.
      • It never fills password, file-upload, card, security-code, one-time-code or CAPTCHA fields.
      • It never runs on a page until you press "Scan this page".
      • It makes no network requests of its own and has no access to your browsing history.
